# WxManimBot

## 这是什么
这是一个支持生成manim动画的微信聊天机器人

## 为什么做这个
周末在家 想diy一个微信机器人和同学玩 后来渐渐有生成manim这个想法 瞎折腾一下

我必须承认 这个小玩意十分简陋 而且这种玩法早就被成熟的实现过了 
我的diy 仅仅是为了和同学一起玩而已 
因此如果你真的对manim生成感兴趣 可以前往一些成熟的项目

## 关于这个聊天机器人
如果你常常diy一些ai应用 相信一眼就能看穿它是如何实现的
使用wxauto 来收发微信信息
使用openai sdk 来接入大模型
使用manim 来生成动画

## 如果你也想试试看
可以填入src/main.py 中的常量字段 然后运行即可
